# Clarity Overview

Quick links and purpose of Microsoft Clarity within the Analytics stack.

## Purpose
- Session replays and heatmaps for qualitative UX insights
- Complements Plausible (quantitative) and Google Ads (attribution)

## Docs
- `IMPLEMENTATION.md` — Full setup and integration guide
- `QUICK_START.md` — 5-minute setup guide

## Key Concepts
- Session tags: `price_variant`, `variant_label`, `funnel_step`, `environment`
- Events: upload, purchase, interactions, performance, errors
- Session upgrade on: completion, checkout, purchase, errors, performance
