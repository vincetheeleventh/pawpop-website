# Analytics Overview

This folder contains the complete Analytics stack for PawPop. Use this overview to jump to detailed docs.

## Stack Summary
- **Plausible**: Quantitative analytics, A/B testing, funnels, goals.
- **Microsoft Clarity**: Qualitative analytics (session replays, heatmaps), UX insights.
- **Google Ads**: Attribution and conversion tracking (docs under `docs/marketing/`).
