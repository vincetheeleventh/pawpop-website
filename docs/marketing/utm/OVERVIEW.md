# UTM Tracking Overview

Standards and practices for UTM tagging across campaigns.

## Docs
- `UTM_TRACKING_GUIDE.md` — How to structure and apply UTMs consistently

## Key Standards
- Use lowercase for all utm_* parameters
- Source and medium must be consistent across campaigns
- Campaign names should be descriptive and versioned
